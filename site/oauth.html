For developers

Connect your app to Conduit

Your users already have models — cloud keys, and ones running on their own GPU. Instead of asking them for an API key, send them to Conduit and let them grant your app access in one click. The same handshake OpenRouter and ChatGPT use, over loopback, with PKCE.

Nothing to register. There is no developer account, no client secret, and no server in the middle. Conduit runs on the user's machine and answers on http://127.0.0.1:8888 by default, once they turn the local API on.

The flow

  1. Make a verifier, send its hash Generate a random string, hash it with SHA-256, base64url it, and open Conduit's authorize URL in the user's browser with that challenge. Keep the verifier; it never leaves your app.
  2. Conduit asks the user Its window comes forward and shows who is asking, what the token allows, and where it will be sent. The browser waits on a small page until they decide.
  3. The browser comes back with a code To your redirect_uri, which must be on this machine (http://127.0.0.1:…, http://localhost:…) or your own URL scheme (myapp://…). Conduit refuses to send a code anywhere else, so it can never be used to leak a grant to a website.
  4. Your app trades the code for a key One POST, from your program rather than the browser, with the verifier. The code is single use and expires in ten minutes. What comes back is an ordinary Conduit token the user can see and revoke in the app.

Code

import crypto from "node:crypto";
import http from "node:http";

const base = "http://127.0.0.1:8888";
const b64 = (b) => b.toString("base64url");
const verifier = b64(crypto.randomBytes(32));
const challenge = b64(crypto.createHash("sha256").update(verifier).digest());
const state = b64(crypto.randomBytes(16));

// A one-shot listener for the code.
const code = await new Promise((resolve) => {
  const server = http.createServer((req, res) => {
    const url = new URL(req.url, "http://localhost:7777");
    res.end("You can close this tab.");
    server.close();
    if (url.searchParams.get("state") === state) resolve(url.searchParams.get("code"));
  });
  server.listen(7777, () => {
    const params = new URLSearchParams({
      client_name: "Your App",
      redirect_uri: "http://127.0.0.1:7777/cb",
      code_challenge: challenge,
      code_challenge_method: "S256",
      state,
    });
    open(`${base}/oauth/authorize?${params}`); // your favourite opener
  });
});

const { key } = await fetch(`${base}/oauth/token`, {
  method: "POST",
  headers: { "content-type": "application/json" },
  body: JSON.stringify({ code, code_verifier: verifier }),
}).then((r) => r.json());

// From here on it is an ordinary OpenAI-compatible client.
const models = await fetch(`${base}/v1/models`, {
  headers: { authorization: `Bearer ${key}` },
}).then((r) => r.json());

import base64, hashlib, http.server, json, secrets, urllib.parse, urllib.request, webbrowser

BASE = "http://127.0.0.1:8888"
b64 = lambda raw: base64.urlsafe_b64encode(raw).rstrip(b"=").decode()
verifier = b64(secrets.token_bytes(32))
challenge = b64(hashlib.sha256(verifier.encode()).digest())
state = b64(secrets.token_bytes(16))

got = {}

class Handler(http.server.BaseHTTPRequestHandler):
    def do_GET(self):
        query = urllib.parse.parse_qs(urllib.parse.urlparse(self.path).query)
        got.update({k: v[0] for k, v in query.items()})
        self.send_response(200); self.end_headers()
        self.wfile.write(b"You can close this tab.")
    def log_message(self, *args): pass

server = http.server.HTTPServer(("127.0.0.1", 7777), Handler)
params = urllib.parse.urlencode({
    "client_name": "Your App",
    "redirect_uri": "http://127.0.0.1:7777/cb",
    "code_challenge": challenge,
    "code_challenge_method": "S256",
    "state": state,
})
webbrowser.open(f"{BASE}/oauth/authorize?{params}")
server.handle_request()
assert got.get("state") == state, "that answer was not for us"

request = urllib.request.Request(
    f"{BASE}/oauth/token",
    data=json.dumps({"code": got["code"], "code_verifier": verifier}).encode(),
    headers={"content-type": "application/json"},
)
key = json.load(urllib.request.urlopen(request))["key"]
print("Conduit key:", key[:9] + "...")

# Anything that can make a URL and a POST can do this.
VERIFIER=$(openssl rand -base64 32 | tr '+/' '-_' | tr -d '=')
CHALLENGE=$(printf %s "$VERIFIER" | openssl dgst -binary -sha256 | base64 | tr '+/' '-_' | tr -d '=')

# 1. Open this in the user's browser:
echo "http://127.0.0.1:8888/oauth/authorize?client_name=Your%20App\
&redirect_uri=http://127.0.0.1:7777/cb&code_challenge=$CHALLENGE&code_challenge_method=S256"

# 2. They approve in Conduit; the browser calls your redirect with ?code=...

# 3. Trade it for a key:
curl -s http://127.0.0.1:8888/oauth/token \
  -H "content-type: application/json" \
  -d "{\"code\":\"$CODE\",\"code_verifier\":\"$VERIFIER\"}"
# {"key":"cnd_...","type":"conduit_api_key"}

# 4. Use it:
curl -s http://127.0.0.1:8888/v1/chat/completions \
  -H "authorization: Bearer $KEY" -H "content-type: application/json" \
  -d '{"model":"local/qwen3-8b","messages":[{"role":"user","content":"hello"}]}'

Parameters

NameWhat it is
client_nameWhat the user sees in the approval window. Use your app's real name; it is shown as a claim, not as a fact.
redirect_uriWhere the code is sent. Loopback or your own URL scheme only.
code_challengebase64url(SHA-256(verifier)), no padding.
code_challenge_methodS256.
stateReturned untouched. Check it before spending the code.

What the token can do

Everything the local API exposes: /v1/chat/completions, /v1/models, /v1/embeddings, Anthropic's /v1/messages, OpenAI's /v1/responses, and Conduit's /v1/decide for decision models. It cannot read the user's provider keys, their conversations or their files — those never leave Conduit, and the keys never leave the operating system's credential store.

If the port is not 8888

Users can change it. Probe the usual suspects with GET /health, which answers {"status":"ok"} without a token, or ask the user for the base URL shown on Conduit's API page.
