what it does

Ten apps you were juggling, in one window.

A chat app, a model runner, a dictation tool, a coding agent launcher, a scheduler, a computer-use agent, an API gateway and a plugin store. Conduit puts them on one set of keys and one history.

A model hub that knows your hardware

Search Hugging Face, pick a quantization, and Conduit tells you whether it fits your GPU before you download a single byte. One click installs the runtime and loads it.

Any provider, every model on your key

Anthropic, OpenAI, Gemini, OpenRouter, Groq, DeepSeek, Mistral, Hugging Face and twenty more. Paste a key and every model it unlocks appears in the switcher, not a hand-picked three.

Hold a key and talk

Dictate into any app, or speak a command. Whisper can run on your own machine, so your voice never leaves it.

It can use your computer

Turn on Screen and Conduit looks, clicks and types for you, with a marker wherever it acts. Esc stops it. It never touches passwords or payments.

screen.capture ✓ screen.click (812, 440) screen.type "tauri docs"

Code mode

Point it at a project folder. It reads before it writes, edits narrowly, and runs your tests before it says it is done.

$ npm test ✓ 89 passed 1.4s

Your own OpenAI-compatible API

Every model in Conduit, local or cloud, behind one endpoint on localhost. Point Cursor, a script or your phone at it. Tokens are stored as hashes, and your provider keys never leave the app.

curl http://localhost:8888/v1/chat/completions \ -H "Authorization: Bearer cnd_…" \ -d '{"model":"local/qwen3-8b","messages":[…]}'

A store for tools, skills and pets

Install MCP servers like Supabase, Notion or GitHub in one click, add skills that teach the agent new workflows, and adopt a desktop pet. Anyone can publish to the open registry.

Claude Code and Codex on any model

Open Claude Code, Codex, OpenCode or Aider on a model running on your GPU, or any provider you use. Their own settings stay untouched.

ANTHROPIC_BASE_URL=localhost:8888 ANTHROPIC_MODEL=local/qwen3-coder

questions

Asked before.

Is it really free?

Yes. Conduit is MIT licensed. You pay your AI providers directly with your own keys, or pay nothing at all by running models locally.

Which computer do I need for local models?

Any machine runs small models on the CPU. A GPU with 8 GB or more runs 7 to 14 billion parameter models comfortably. The model hub reads your hardware and marks every download as fits, partly fits or too big.

Does my data go anywhere?

Only to the provider you pick for a given chat. With a local model, nothing leaves your computer. There is no Conduit server in the middle and no telemetry.

Can it break things on my computer?

By default it asks before running commands, deleting files or touching the screen, and shows you the exact command. You can loosen or tighten that from the shield in the message box.

How is the API different from running a model server?

It serves every model Conduit can reach, local and cloud, behind one OpenAI-compatible address, with tokens you create and revoke. Your apps get one endpoint; your provider keys stay in the keychain.
